# 🙏 Ayyappa Mala Tracker

A modern, secure, **100% Free and Open Source (FOSS)** Android application built with **Jetpack Compose** and **Material 3** for tracking and following the **Ayyappa Mala Vratham** (Mandala/Makara Vilakku 41-day observance).

> **Note**: This project was **vibe coded** for personal sadhana.

---

## ✨ Features

- **🌅 Daily Sadhana Checklist**: Track morning/evening cold baths, continuous Mala & Rudraksha wearing, morning & evening puja (Namajpam & Harivarasanam), strict Sattvic diet, Brahmacharya (celibacy), truth & patience, and temple/bhajan attendance.
- **🖤 True AMOLED Dark Theme**: Sleek pitch-black (`#000000`) theme with vibrant Saffron and Sacred Gold accents for battery efficiency and high-contrast readability.
- **📜 Detailed History & Analytics**: View past daily records with exact completed observances (badges/chips) and personal spiritual journal reflections.
- **📖 Guide & Sacred Mantras**: Built-in reference for Mala rules, dress code, dietary discipline, and the **Harivarasanam** lullaby.
- **🔒 100% Local & Secure**: All data is stored locally on your device files (`context.filesDir`). No cloud tracking, login required, or data collection.
- **📤 Export & Import Data**: Easily backup or restore your sadhana progress using JSON export/import via Android's Storage Access Framework.

## 🛠️ Tech Stack & Architecture

- **UI Toolkit**: Jetpack Compose (Material 3)
- **Architecture**: MVVM (Model-View-ViewModel) with Kotlin Coroutines & StateFlows
- **Storage**: Local JSON file repository (`org.json`) with SAF (Storage Access Framework) file export/import
- **Min SDK**: API 35+
- **Compile SDK**: API 37+
